## 两个增量只读 API

### 调度时间预览

`POST /api/schedules/preview`，沿用业务 API 的已认证 Principal；普通已认证账号可预览，未认证请求拒绝。此接口没有适配器标识，不授予适配器编辑/启用能力。

- 请求：`cron: string`（1–256 字符）、`timezone: string`（1–128 字符）、`count: integer`（默认 3，范围 1–10，不接受布尔值）。
- 响应：`{ "occurrences": [ISO8601时间, ...] }`，使用正式调度器相同的五段 Cron 校验、时区与下一计划点算法，以服务端当前时间向后计算。
- 非法 Cron、时区或数量返回 422；无支持范围内未来时间也拒绝。不创建或修改适配器、Schedule、启用状态、计划游标及执行记录，不触发 Worker。
- 响应不含代码、输入或凭据。前端将预览与已保存状态分开，草稿变化使旧结果失效；浏览器不支持服务端时区时显示带时区 ISO 原值。
- 这些时间是**计划点**，不是实际执行承诺。既有 `next_run_at` 同样是下一计划游标；输入校验、容量、排队、补跑与运行门禁仍可能影响实际执行。

### 凭据使用位置

`GET /api/credentials/{credential_id}/usage`，沿用凭据目录的管理员门禁：部署超级管理员或账号管理员可用，普通账号返回 403，未认证返回 401，不存在的凭据返回 404。

- 响应：`{ "items": [{ "kind": ..., "name": ..., "adapter_id": 可空, "detail": 可空 }] }`。
- `kind` 为 `adapter_binding`、`webhook`、`ai_model`、`ai_custom_provider`、`knowledge_source` 或 `package_source`；适配器引用排除已归档对象，返回当前配置的实际关联。
- 只返回名称、类别、可选适配器标识和绑定名称等元数据，不解密凭据，不返回密文、秘密字段或连接地址；不修改配置或绑定。
- 空结果只说明本次查询没有返回可显示的当前配置引用。它不是运行历史/不可变快照的全局依赖证明，也不表示删除凭据一定安全。
