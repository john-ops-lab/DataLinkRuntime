# Issue #117 Batch 3 browser evidence

This directory contains the Batch 3 browser evidence for the live-log pause and
resume contract. The fixture is local and anonymous; it uses only the safe
placeholder `EXAMPLE_ADMIN_TOKEN` and does not use provider credentials.

## Evidence layers

### AO Browser live SSE flow

The AO Browser session performed the real interactive flow in both `zh-CN` and
`en`: open the live log, pause following, let the fixture continue collecting
and reach its terminal snapshot, confirm the visible text remains frozen, resume
following, and confirm the ordered terminal text is present once. The same flow
also exercised maximize and `Escape` restore.

- `ao-zh-CN.log-text.json` records the resumed ordered text, including both
  pause-window lines and the terminal line with `[REDACTED]`.
- `ao-zh-CN.network.json` records metadata-only `200` responses for both
  `/api/executions/5/events` (SSE) and `/api/executions/5` (snapshot), with no
  unexpected API errors.
- `ao-zh-CN.errors.json` is empty; `ao-zh-CN.console.json` contains only Vite,
  React DevTools and i18next informational/debug messages.
- `ao-en-live.snapshot.json`, `ao-en-live.errors.json` and
  `ao-en-live.console.json` record the corresponding English live-log page and
  clean page-error state. `ao-en.network.json` is intentionally marked as a
  terminal reload capture (`execution_events_sse: false`); the live SSE request
  is evidenced by the zh-CN capture, while the English AO Browser interaction
  and screenshots cover the English UI path.
- `live-zh-CN-paused.png`, `live-zh-CN-paused-after-sse.png`,
  `live-zh-CN-resumed.png`, `live-en-paused.png` and `live-en-resumed.png`
  are the interaction screenshots.

The exact scroll-position freeze/resume assertion is covered by the focused
`LiveLogWorkspace` test: it preserves `scrollTop=70` while paused and restores
the followed tail at `scrollTop=700` after resume.

### Scoped Playwright/Chromium width matrix

`playwright-browser-matrix.json` is generated by a temporary scoped script
against the same local anonymous fixture. It is separate from the existing
`web/tests/e2e/m5-11-wave-v3-workbench.spec.ts` and was used only for the Batch 3
layout/visible-state matrix:

- locales: `zh-CN`, `en`
- viewport widths: `1280`, `1440`, `1680`, `1920` (height `900`)
- visible states: workbench, live log, pause, resume, maximize and `Escape`
- long-log wrapping and document/body/live-log horizontal overflow
- per-page console errors, page errors, request failures and HTTP error metadata

All eight records have `pause_content_frozen: true`, no console/page/request
failures, no HTTP errors, and equal document/body scroll widths to the viewport
width. The sixteen `matrix-*.png` files are the paused/resumed screenshots for
the eight locale-width cases.

The pre-existing `m5-11-wave-v3-workbench.spec.ts` was not modified and is not
part of this Batch 3 gate. Its anonymous-fixture run failed at `0ms` before a
product assertion; this is classified as an out-of-scope external test-asset
failure (including its incompatible fixture/browser preconditions), not as a
Batch 3 product result.
