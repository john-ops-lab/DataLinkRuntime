# #215 真实模型样例

两个文件是已配置 MiniMax-M3 的真实候选原文，使用合成订单汇总需求，无凭据、网络或文件操作：

- `provider-zh-python.py`：系统中文，以英文提出已知无穷值问题的修复请求；中文说明与 `math.isfinite` 行为一致。
- `provider-en-go.go`：系统英文，以中文修复请求提供含旧中文入口注释的代码；返回完整英文注释，保持运行入口。

两份候选均在实际 Worker 上分别执行混合 9 行输入和 `rows: null`，输出符合 [验收文档](../../testing/issue215-ai-assistant.md) 的独立预期。样例取自针对性第二轮；完整代码的小改动、页面重新生成和最新提示词的验收另见 PR 交付记录。样例通过不代表任意模型生成均正确，应用仍需人工审查。
