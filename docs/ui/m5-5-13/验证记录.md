## Auto Review 阻塞项修复（拖动入口，review 4949200727）

1. **首次拖动瞬移**：`startOffset` 改为 pointerdown 时 `getBoundingClientRect()` 的
   当前实际渲染位置（并转换为包含块坐标），不再从 (0,0) 起算；真实浏览器断言
   拖动 delta 与指针移动完全一致（`before.x=1378 → after.x=1178`，delta -200）。
2. **translateY(-50%) 残留**：拖动定位生效时内联 `transform: none` 覆盖默认
   垂直居中 transform，钳制坐标即实际渲染坐标；顶部钳制后按钮完整留在视口内
   （`top=846 bottom=892`，无 23px 偏移）。
3. **（真实验证中发现的同源问题）**：内联 left/top 从按钮移到绝对定位的悬浮
   宿主 `<aside>` 上（否则坐标相对 46×46 的按钮自身），且钳制边界改用包含块
   （`.console-body`，position:relative）尺寸而非视口——水平钳制精确命中
   `right=1432=1440-8`，垂直钳制命中 `bottom=892`，均真实渲染。
4. 回归测试更新：`drags the floating entry...` 用例注入 `getBoundingClientRect`
   假实际位置，固化「从当前位置跟随指针」「transform:none」「钳制不出包含块」。
5. Review 标注的 OutputView 次要项（跨 pre 选区判定一致性、行号多计）按
   review 意见不扩大范围修复。
