## 本批次代码修复（普通回归范围）

**Monaco DiffEditor 卸载时序警告（M5.5.6 浏览器验收中发现）**

- 现象：打开/关闭版本差异 Modal 时页面产生
  `TextModel got disposed before DiffEditorWidget model got reset`
  （Monaco `BugIndicatingError`，经 window error 事件上报）。
- 定位：`VersionDiffModal` 使用 `Modal destroyOnHidden`，关闭时
  `@monaco-editor/react` 默认先 dispose 内部 model 再 dispose DiffEditorWidget，
  触发卸载时序竞争。该文件自 M3.2（3bd1615）起即存在此行为，非 M5.5 引入的回归，
  但属于普通前端缺陷，在本 Issue 收敛。
- 修复：为 DiffEditor 固定 `originalModelPath` / `modifiedModelPath` 并开启
  `keepCurrentOriginalModel` / `keepCurrentModifiedModel`，使 model 由 Monaco
  model 缓存复用（不再卸载时 dispose），消除竞争且不产生孤儿 model。
- 验证：工作副本 Diff 与 AI Candidate Diff 打开/关闭 3 轮、pane 切换均无该
  错误；web lint / typecheck / vitest（123 个）/ build 全绿。

**已知既存警告（不修复，如实记录）**

- `Missing requestHandler or method: findDocumentSymbols / findDocumentColors /
  getFoldingRanges / resetSchema`：`editor-setup.ts` 自 M1（05dbb2f）起仅注册
  editorWorker 与 Python 语言注册，JSON Diff pane 触发语言服务 worker 缺失警告；
  语法高亮等核心能力正常，无功能影响。修复需引入额外 language worker，超出
  本批次普通回归范围，按「如实记录不隐藏」处理。
