## 四、完整产品流程回归（真实 compose 栈）

### Task
新建 → 默认 Starter Code（凭据读取注释）→ 编辑 / 依赖 / 凭据绑定（demo-passwd +
PASSWORD）→ 保存 → 运行设置（手动/定时）→ 单次执行超时（默认 300）→ 运行一次 →
实时日志 Tab（自动跟踪）→ 执行记录/详情 → 运行锁（定时 Radio 运行中禁用）。
**PASS**（浏览器 + API + compose-smoke 链；定时到点执行由 pytest
`test_schedule_trigger` 14 用例与 compose-smoke schedule 链覆盖）。

### Webhook
新建 → 默认 Starter Code + demo-token → path / 完整地址 / 访问凭据 / Worker /
timeout → Save（首存需先绑定 Token Credential，409 门禁验证）→ 开启接收 →
POST（202）→ 实时日志 Tab → 调用记录/详情 → 停止接收（无 active 直接停；有 active
三选一弹窗）→「直接结束当前调用」真实 cancel。**PASS**。

### AI
悬浮入口 → 打开面板 → Monaco 选区加入上下文（自动展开）→ 日志选区加入上下文 →
多片段 → 提交需求 → Candidate → 查看修改 → Diff → Apply → Diff 自动关闭 →
Working Copy 已应用标记。**PASS**。安全边界：fake Provider 全程；Secret 真值不
进入 Prompt / 日志（compose-smoke 断言 SMOKE_STORED_SECRET / SMOKE_SELECTED_TEXT /
SMOKE_LOG_TEXT 不出现在 control/worker/web 日志）；hidden reasoning 哨兵不返回
浏览器（compose-smoke + pytest test_ai）。

### 系统设置
凭据管理四类说明 → 新建 Credential 一次性明文 confirm 提醒 → 创建后仅元数据 →
依赖源默认值（aliyun PyPI / npmmirror / aliyun Maven）展示。**PASS**（修改/恢复
默认由 pytest `test_package_sources` + web 测试覆盖）。
