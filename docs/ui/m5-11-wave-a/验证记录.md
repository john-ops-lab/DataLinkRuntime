# M5.11 Wave A 验证记录

## 范围

本记录只覆盖 Issue #107 的 Wave A：应用框架与导航、独立设置中心、固定视口与滚动边界、Token/账号统一登录壳层，以及登录前语言选择。未实现 Wave B 日志业务、Wave C Adapter 永久删除/Webhook 语义或 Wave D AI Provider/知识库能力。

所有浏览器与 Compose 场景均使用本地 fixture、假 API 和假凭据；未连接生产服务或使用真实 Secret。

## Web 自动化

命令（工作目录 `web/`）：

```text
npm ci
npm run typecheck
npm run lint
npm test -- --reporter=dot
npm run build
DLR_BROWSER_BASE_URL=http://127.0.0.1:4174 npm run test:browser -- tests/e2e/m5-11-wave-a.spec.ts
```

结果：

- Vitest：`27 passed`，`311 passed`。
- typecheck、ESLint、Vite build：通过。
- Playwright Chromium：`10 passed`，覆盖 `zh-CN/en` 与 `1280/1440/1680/1920` 宽度；另覆盖账号强制改密、`125%` 缩放、账号只读权限和直接设置路由。
- 每个 Playwright 场景均检查未知请求、非预期 console error、page error、文档/ body 横向溢出；管理员场景的设置内容滚动边界为 `overflowY=auto`。
- 账号登录的预期会话 bootstrap `401` 单独记录为 `expectedConsoleErrors`，非预期 console/page errors 均为空。

证据：

- 汇总：`docs/ui/m5-11-wave-a/browser-report.json`
- 截图：`docs/ui/m5-11-wave-a/browser/`（26 张）
- Playwright spec：`web/tests/e2e/m5-11-wave-a.spec.ts`

AO Browser 真实检查打开 `http://127.0.0.1:4174/`，快照显示登录壳层、Token 输入和登录前语言 Select；`ao browser errors` 无浏览器错误。
