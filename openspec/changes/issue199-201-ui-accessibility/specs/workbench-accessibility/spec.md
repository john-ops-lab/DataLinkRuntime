## Purpose
定义工作台新建适配器及凭据表单的可访问交互合同，确保用户能够通过可见键盘焦点识别当前操作、在弹层内修正关联字段错误，并在取消或退出后回到合理的触发入口，不产生草稿持久化。
## ADDED Requirements
### Requirement: 新建适配器具有可见的初始焦点和循环
新建适配器弹层 SHALL 把初始焦点放在可理解的可见字段；前向与反向 Tab MUST 在可见可操作控件间循环且保留弹层焦点约束。Escape、关闭和取消 SHALL 返回可见触发入口，取消 MUST 不创建对象。
#### Scenario: 打开和首个 Tab
- **WHEN** 用户从目录新建入口打开弹层并连续按 Tab、Shift+Tab
- **THEN** 初始和每个稳定落点可见且有名称，字段及创建/取消可达，首尾循环不在隐藏 DIV 停留
#### Scenario: 关闭弹层
- **WHEN** 用户按 Escape、点击关闭或取消
- **THEN** 触发入口恢复焦点且不提交创建草稿
### Requirement: 凭据必填错误关联对应字段
凭据表单 SHALL 在 dialog 内提供对应字段的错误说明、aria-invalid 和描述关联。用户修正、切换字段类型或重新打开表单时 MUST 清除过期状态。服务端校验 SHALL 保留，空名称或其他必填字段错误 MUST 不提交创建请求。
#### Scenario: 空名称提交
- **WHEN** 新建凭据名称为空或仅空白并提交
- **THEN** 名称输入声明无效且可通过描述 ID 获得原因，键盘可修正或取消且不创建凭据
#### Scenario: 其他字段和错误恢复
- **WHEN** 当前凭据类型的必填字段为空或用户修正先前错误
- **THEN** 错误关联到相应输入，修正后清除过期说明及状态，取消返回触发入口且不提交草稿
