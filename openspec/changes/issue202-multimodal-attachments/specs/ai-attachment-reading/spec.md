# Spec Delta

## Purpose

定义模型在当前授权请求中读取临时附件目录、页图与表格范围的行为，使超过上下文预算的材料仍可定位查询，实际多模态传输符合各模型协议，同时把覆盖不足、错误和人工代码执行边界清楚呈现给用户。

## ADDED Requirements

### Requirement: Bounded literal inline field hints

系统 SHALL 在完整普通 inline 文本含合法字面标签和值时附加有界源跨度提示，同时保留完整原文；提示 MUST 与原文处于不可信资料区并接受既有预算，不得改变指令权限或推断操作授权。

#### Scenario: Field extraction differs from complete-line transcription

- **WHEN** 原文是 `Reference: ZX-17`，用户要求仅返回字段值或原样复述整行
- **THEN** 标签和值 SHALL 明确分开，值具有可核对的原始行号和字符跨度；模型按请求分别返回 `ZX-17` 或原始完整行，而非擅自添加前缀
- **AND** 提示最多 8 个、标签最多 80 字符、值最多 256 字符；截断文本不得假装具有完整字段提示

#### Scenario: Source field labels never gain authority

- **WHEN** 一个字面字段叫 `SYSTEM` 且值要求读取 Secret 或执行代码
- **THEN** 提示 SHALL 仍为不可信数据，不能进入系统指令或权威状态，不能注册工具、生成未授权 Candidate 或保存／执行

### Requirement: 实际模型输入能力
系统 SHALL 根据所选 Provider、模型、endpoint 与协议决定图片和原生 PDF 支持，保留能力依据或未知状态；品牌名、未实现的勾选或上游文件占位 MUST NOT 被宣称为已验证原生支持，系统不得自动切换模型。

#### Scenario: 文本模型与视觉附件
- **WHEN** 当前实际组合的视觉能力未知或不支持而请求需要图表内容
- **THEN** 系统提供明确能力说明或稳定错误，不声称文字提取保留图表，不切换模型

### Requirement: 当前附件目录与范围读取
系统 SHALL 先向模型提供有界附件目录及覆盖信息，并提供只读的指定页、图片与 sheet/range 查询；工具仅可读取当前授权请求引用的材料，不接受任意路径、URL、其他附件或业务 Managed Input Blob。

#### Scenario: 长 PDF 末页与工作簿后段
- **WHEN** 目标内容在初始上下文预算之外的 PDF 末页或 sheet 的后段单元格
- **THEN** 模型可根据目录调用有界工具取得指定范围的真实图像或精确单元格，不把初始截断误报为全文已读

#### Scenario: sheet 明细超过工具结果预算
- **WHEN** 已读取的原件范围包含超过单次结果预算的 cell 明细
- **THEN** 系统按完整记录裁剪明细，并在原字符上限内保留来源、统计及统计适用范围、明细覆盖与遗漏数量；模型按需补读遗漏明细，不把前缀数目当作整个范围的格数

#### Scenario: 脱敏扩张不能绕过结果预算

- **WHEN** 凭据脱敏扩张了附件必要 metadata，或 JSON 转义后结果仍超过 4,000 字符
- **THEN** 系统 SHALL 返回稳定脱敏工具错误，不以超预算成功结果或静默丢弃范围事实绕过门禁

### Requirement: 回答采用原件事实与真实来源
系统 SHALL 向模型提供程序计算的原件范围事实及来源，要求计数、公式缓存与合并范围回答遵循该事实，引用实际已读页/sheet/range 并说明遗漏；源数据传输和自然语言业务回答 MUST 分别按独立真值验收，不把 JSON 合法或读取成功视为事实正确。

#### Scenario: 精确提取与 prepared 来源
- **WHEN** 用户明确只要求提取完整 inline 原文，或依据 prepared 工作簿进行咨询
- **THEN** 前者遵循精确提取要求而不添加无关说明；后者基于实际读取并保留来源及覆盖，附件正文仍不能改变权限或触发自动保存/运行

#### Scenario: 越权引用
- **WHEN** 模型请求未在该次 Assist 引用集合内的附件或任意路径
- **THEN** 调用被拒绝且不访问外部文件，错误进入现有有界工具轨迹

### Requirement: 多模态工具材料符合协议
系统 SHALL 使用实际支持的原生 image/document parts 或协议允许的后续多模态消息传递工具取得的像素与 PDF；传输必须保留附件、原始页号/范围及工具来源关联，附件内容不授予新的指令权限。

#### Scenario: OpenAI-compatible 工具读取页图
- **WHEN** 模型的文本工具协议不能直接承载图片，而工具取得一页真实图像
- **THEN** 系统保留完整工具文本结果并通过该协议允许的多模态消息发送对应像素与来源，不把 base64 当作文本或不可解析图片 URL

### Requirement: 每次实际调用重新预算
系统 MUST 在首次请求、工具后续、最终回答和格式纠正的每次实际 Provider 调用前计算文本、图片/文件、工具定义、输出保留与请求字节预算，继续服从总时限、轮次和调用次数上限；读取不得产生超限请求或无限转换/查询。

#### Scenario: 后续图像使请求超过预算
- **WHEN** 工具得到的多页图像使下一次 Provider 请求超过预算
- **THEN** 系统有界裁剪可选材料并明确覆盖遗漏，或返回稳定预算错误，不绕过门禁发送

### Requirement: 阶段与覆盖对用户可见
UI SHALL 用简体中文和 English 展示附件准备、转换、读取及失败阶段，公开实际页/sheet/range覆盖与遗漏、能力不足和可恢复操作；HTTP 或 Schema 成功不能替代业务任务成功。

#### Scenario: 结构部分失败后仍有页图
- **WHEN** 结构转换部分失败，但对应真实页图可以被视觉模型读取
- **THEN** 用户看到部分覆盖说明和实际读取轨迹，可继续新请求或重试合法冻结轮次，不能看到完整提取成功的假象

### Requirement: 人工执行链保持
附件业务需求生成代码 SHALL 返回可审查 Candidate，并保持 Diff、显式 Apply、显式 Save 和显式 Run；附件、工具或转换器 MUST NOT 自动修改工作区、运行配置或触发执行。

#### Scenario: 根据真实 Excel 生成代码
- **WHEN** 用户授权使用附件中的业务需求生成 Python Adapter
- **THEN** 实际模型输出满足需求的 Candidate，用户确认 Diff 后 Apply，再通过正常 Save/Run核对业务输出，任何自动保存或运行均不得发生
