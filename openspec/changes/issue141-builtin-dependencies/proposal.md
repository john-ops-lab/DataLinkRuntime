## Why

客户 Worker 无公网且没有企业仓库时，适配器需要可持久管理的离线安装材料。实现 GitHub #141；范围包括 Python、JavaScript、Java。

## What Changes

- 管理员可上传、筛选、下载、实际删除内置库文件，三种语言共用默认 1 GiB 可调容量。
- 每类依赖源增加初始非默认的 DLR 内置依赖源；现有外部源和选择保持不变。
- 任务接受时冻结内置材料身份并阻止占用文件删除。Worker 校验下载内容，使用原生包管理器在独立环境安装，缺包不外部补源。
- 提供指定 Worker 安装检查及离线材料、备份恢复说明。

## Capabilities

### New Capabilities
- `builtin-dependencies`: 控制节点离线依赖库及 Worker 安装链路。

## Impact

新增数据库迁移、持久卷、管理 API、任务快照字段、Worker 安装分支和管理页面。回滚前停用内置源并排空相关任务，保存数据库及库文件；不自动删除管理员材料。不扩展语言，不实现适配器独立选源、完整公网镜像、包禁用或 #142 导入导出。
