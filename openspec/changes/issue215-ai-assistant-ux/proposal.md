# Proposal

## Why

AI 助手的说明与发送内容预览占据输入区，展开时会挤走发送操作。用户已确认 v2 设计，并要求生成代码默认按系统语言充分加注释；后续确认移除查看发送内容功能，并将输入文字与对话正文字号统一。

## What Changes

- 实现 v2：顶部保留模型、临时对话标识和更多菜单；输入工具栏仅有附件及发送。
- 删除动态发送内容预览，仅将使用说明放入独立对话框，保留临时聊天、附件和人工 Candidate → Diff → Apply 流程。
- 收窄侧栏，最大化模式限制内容阅读宽度；中英文同步。
- 将中文／英文代码注释要求加入统一系统提示词，覆盖生成、修改、重新生成和附件驱动代码建议。

## Capabilities

### New Capabilities

- `ai-assistant-workspace`: AI 助手的紧凑布局、统一文字尺寸与按需帮助、保持可见的发送操作。
- `ai-code-comment-language`: 按服务端系统语言输出充分且准确的代码注释。

### Modified Capabilities

无。现有 OpenSpec 主规格尚未覆盖上述能力，历史里程碑文档不改写。

## Impact

仅修改 AI 页面组件、样式、双语文案及 Prompt 资源／组装与对应测试，不新增依赖、API、数据库迁移、模型选择或会话持久化。保持现有权限、凭据、请求快照和运行契约。部署使用现有私有验收配置和持久卷；无数据迁移及数据库回退需求。
