# B0 Stage Statistics

## Scope and Method

正式 200 条的完整阶段统计；预热不在表内。各阶段均使用同一平台 VM 的 monotonic，结束点为 start_ns + elapsed_ns。单位均为毫秒，分位数采用 nearest-rank：排序后取 ceil(N × p) 项。表内保留原始统计的所有样本，不剔除失败或慢样本。

本表列出 49 项观测，含子阶段的总路径不能与子阶段重复相加；锁调用是查询执行与等待的组合。来源 ACK 和内部 ACK 指调用/发送回执边界，不表示 Broker 对消费者 ACK 另发确认。跨 VM 精确接管时延未测得，不能从 UTC 补算。

“前序”项只有 199 个相邻责任对；“接管且前序结清后”项的起点是两项条件较晚的满足时刻。完整方法、逐 ID 配对和输入文件指纹保存在私有验收账本。

## Interpretation

负值列用于显式保留边界交叠，不能把跨线程/组合边界强行串行相加；本表正式 49 项记录的负值数以原始统计为准。SQL 的明细另有抽样，其全量 P95/P99 只报告精确桶区间，不与本表完整逐 ID 阶段分位数混用。

瓶颈、资源、时钟边界和下一批建议见 [B0 报告](b0-results.md)；测量合同见 [B0 计划](b0-measurement-plan.md)。
